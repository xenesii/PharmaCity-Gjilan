# Pharma City Login (Flutter)

This is a Flutter (Dart) app that recreates and improves the login page shown in your template image.

## Run

1. Install Flutter (SDK) from the official site:
   - https://flutter.dev/docs/get-started/install
2. (Optional) If you want to run on Web:
   - `flutter config --enable-web`
3. From this folder (`C:\Users\hi\Desktop\pharmacy`), run:
   - `flutter pub get`
   - `flutter run -d chrome`

If `flutter run` complains about missing platform folders (android/ios), run:
`flutter create . --platforms=web`
and then re-try the commands above.
